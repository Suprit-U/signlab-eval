# Architecture

## Goals

1. A detector score you can reproduce months later, from a file on disk.
2. A dataset check that catches the two mistakes which quietly inflate a score:
   leakage and missing labels.
3. Zero required dependencies. Anything optional stays optional.

## Layout

```
src/signlab/
  dataset.py     discovery + parsing: root -> Dataset -> Split -> ImageSample
  validate.py    findings, severities, leakage detection
  metrics.py     Box, IoU, matching, AP, mAP, EvalReport
  predictors.py  Predictor protocol, JsonlPredictor, optional UltralyticsPredictor
  report.py      JSON + dependency-free HTML
  cli.py         validate | evaluate | report, exit codes
```

## Dataset discovery

`load_dataset(root, splits=None)` looks for `train`, `val`, `test` under
`images/<split>`. If none of those subdirectories exist it falls back to a flat
`images/` + `labels/` layout — and only then, so a missing split is reported as
missing instead of silently resolving to an empty one.

Class names come only from `classes.yaml`, `classes.yml` or `classes.json`. A
`classes.txt` is ignored on purpose: the file alone does not say whether it is
indexed by line number or by class id, and guessing is how class drift enters a
dataset.

`ImageSample` carries its own issues. Parsing never raises for a malformed
label; the sample records the problem and the validator decides the severity.
A tool that stops at the first bad file is a tool nobody runs twice.

## Matching and AP

For each image, detections are sorted by descending score and greedily matched
to unmatched ground truth of the same class with `IoU >= threshold`. The greedy
score-ordered pass is what makes the result independent of input order.

Precision-recall points come from every detection that produced a change in the
curve, and AP integrates precision over recall with all-point interpolation.
There is no 11-point subsampling, so the number is comparable with COCO-style
reporting.

`mAP@50-95` is the mean of the ten per-threshold APs. Classes with no ground
truth in the split are skipped and listed separately instead of being averaged in
as zeros, because a zero there is a reporting artefact, not a model failure.

## Leakage detection

`train-val-overlap` is an exact match on image id — cheap, and it catches the
copy-paste mistake.

`duplicate-image` uses a dHash perceptual hash (8x8 difference hash, Hamming
distance 2) so a re-encoded or lightly resized copy is still caught. Without
Pillow the hash degrades to a content hash: byte-identical duplicates are caught,
visual near-duplicates are not, and the finding says which mode ran.

## Exit codes

`0` ok · `1` the quality gate failed · `2` the dataset is invalid · `3` usage or IO error.

This separation is deliberate: a red build caused by a broken dataset should not
look the same as a red build caused by a model regression.

## Deliberate non-goals

- **Training.** signlab measures; it does not fit.
- **Box formats other than YOLO and xyxy JSON.** COCO JSON and Pascal VOC need
  different loaders and would each need their own tests to be trustworthy.
- **A plotting dependency.** The HTML report is generated by string building and
  the shared style block. It is readable, small, and has nothing to install.
